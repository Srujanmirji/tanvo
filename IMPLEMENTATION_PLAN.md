# TANVO Implementation Plan

Build in this order.

## Phase 1, foundation

1. Vite + React + TypeScript
2. Tailwind
3. global typography
4. design tokens
5. responsive grid
6. Lenis
7. navigation
8. route/page structure

Do not build the entire site yet.

## Phase 2, hero

1. Hero layout
2. Typography
3. CTA
4. Three.js renderer
5. Crystal geometry
6. materials
7. lighting
8. particles
9. pointer interaction
10. scroll transformation

Stop and visually polish.

## Phase 3, storytelling

Build:

1. IDEA
2. VISION
3. DESIGN
4. BUILD
5. LAUNCH
6. IMPACT

Connect the visual transitions.

Do not make them independent WebGL scenes if a shared scene can create a better transition.

## Phase 4, work

Build:

1. selected work
2. project data
3. large visuals
4. hover interactions

## Phase 5, services

Build the editorial service list and hover visual system.

## Phase 6, approach and trust

Build:

- approach
- metrics
- placeholder client marks

## Phase 7, final CTA

Build the portal and final CTA.

## Phase 8, footer

Build the footer.

## Phase 9, integration

Connect:

hero → idea → vision → design → build → launch → impact → work → services → approach → trust → CTA

## Phase 10, polish

Review:

- typography
- spacing
- animation
- WebGL
- responsiveness
- accessibility
- performance

## Phase 11, production audit

Run the QA checklist.

Fix all errors before considering the project complete.

## Critical rule

Do not redesign completed sections while building new sections unless integration requires a change.

Preserve working code.

Make small, controlled changes.

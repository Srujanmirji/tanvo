# TANVO, Antigravity Build Pack

This folder contains the complete planning and implementation instructions for building the TANVO agency website.

## Start here

Read:

1. AGENTS.md
2. PROJECT.md
3. DESIGN_SYSTEM.md
4. ARCHITECTURE.md
5. IMPLEMENTATION_PLAN.md

Then use the remaining files as technical references.

## Recommended Antigravity workflow

Give Antigravity the project files and ask it to read AGENTS.md first.

Then tell it:

> Read AGENTS.md, PROJECT.md, DESIGN_SYSTEM.md, ARCHITECTURE.md and IMPLEMENTATION_PLAN.md. Do not implement yet. First inspect the repository and propose the implementation plan based on these files.

After reviewing its plan, start implementation phase by phase.

## Reference

The visual direction should follow the TANVO cinematic agency concept:

- dark premium environment
- large editorial typography
- crystalline hero object
- violet energy
- particle transformation
- wireframe landscape
- floating product interfaces
- code/data environment
- cinematic launch
- portfolio ecosystem
- final glowing portal

The goal is a real interactive website, not a static design mockup.

# TANVO Website, Antigravity Build Instructions

## Mission

Build TANVO as a premium creative technology agency website.

Core statement:

> WE BUILD WHAT YOU IMAGINE.

TANVO turns ambitious ideas into real digital products, websites, AI experiences, brands, and immersive digital experiences.

The website itself must act as TANVO's strongest portfolio piece.

It should feel like an Awwwards-level creative technology experience, not a conventional agency website.

## Non-negotiable principles

1. Build the actual interactive website, not a static mockup.
2. Use Three.js for the visual experience.
3. Use GSAP and ScrollTrigger for scroll-driven storytelling.
4. Use Lenis for smooth scrolling.
5. Keep the UI minimal while making the visual experience rich.
6. Desktop is the primary experience.
7. Preserve the story across every section.
8. Do not use generic SaaS templates.
9. Do not overuse glassmorphism, gradients, rounded cards, or random animations.
10. Do not invent real clients, testimonials, awards, or business statistics.
11. Keep all content configurable.
12. Do not rewrite completed sections unnecessarily when implementing later sections.

## Story

The complete experience follows:

IDEA → VISION → DESIGN → BUILD → LAUNCH → IMPACT

Visual continuity:

Crystal → fragments → particles → wireframe → interfaces → code/data → product → portfolio → final portal

## Stack

- React
- TypeScript
- Vite
- Three.js
- React Three Fiber where useful
- GSAP
- GSAP ScrollTrigger
- Lenis
- Tailwind CSS
- GLSL shaders where useful

Avoid adding libraries unless they solve a real requirement.

## Quality bar

The final result must feel:

- premium
- cinematic
- experimental
- precise
- technological
- confident
- minimal
- memorable

The visitor should leave thinking:

> TANVO can build the thing I have been imagining.
